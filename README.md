# After Hours · 夜局

给朋友内部使用的私人德州扑克网页，支持 **2–11 人**，手机和电脑浏览器均可加入。

[GitHub 仓库](https://github.com/horoling/after-hours-poker)

## 功能

- 创建私人房间，通过完整邀请链接加入，无广告。
- 支持 6／7／9／11 人等不同桌型；房主可在两手之间调整人数。
- 无限注德州：自定义合法加注、全下、主池与边池、平分及无人跟注筹码退回。
- 连续保留筹码、轮庄、改昵称、两手之间补码和离桌。
- 默认每次行动 30 秒，可调整或关闭；显示剩余秒数及进度条，支持暂停和超时过牌／弃牌。
- 同一浏览器刷新或断线后恢复座位；房间和牌局保存至 SQLite。
- 手机布局，保留最近 50 手结算。
- 整场统计：全桌盈亏榜、时长、参与／获胜手数、最大底池、可筛选的盈亏曲线，以及总账／逐手 CSV 导出。
- 房主可在两手之间结束本场，固定最终账单。离桌账目保留，重新加入作为新记录。
- 房间文字聊天，支持中文、emoji、换行、昵称／时间、未读提示和重连同步；赛后也可继续聊天。
- 默认小盲 1 / 大盲 2，无前注；显示 D、SB、BB、UTG 等本手实际位置。
- ½ 底池、1 底池、All-in 快捷选额，手机滑杆和精确金额输入；确认后下注。
- 电脑快捷键：F 弃牌、C 过牌／跟注、1 半池、2 满池、A 选择全下、R 确认加注。输入框和对话框内不会触发这些快捷键。

规则由 PokerKit 执行，服务器校验玩家身份、行动顺序和下注金额，并按座位过滤底牌。

## 本机运行

需要 Python 3.11 或以上版本。

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements-multiplayer.txt
.venv/bin/python multiplayer_app.py
```

打开 <http://127.0.0.1:8780/friends> 创建房间。

## 手机与电脑在同一个 Wi-Fi 测试

```sh
HOST=0.0.0.0 .venv/bin/python multiplayer_app.py
```

电脑保留创建房间时使用的浏览器页面。在邀请链接中，将 `127.0.0.1` 替换为电脑的局域网 IP，端口、房间路径及 `#invite=...` 部分保持完整；手机浏览器打开替换后的链接，再输入另一个昵称入座。至少两位有筹码的玩家即可开局。

电脑需要保持运行；网络应允许设备互访，并允许 Python 的传入连接。

## 测试

```sh
.venv/bin/python -m unittest discover -s tests -v
node --check web/friends.js
```

54 项后端测试覆盖多人对局、底牌隔离、加注权、全下边池、零头、盲注顺序、重连、并发重复提交、底池比例加注、位置随轮庄更新，以及整场统计、补码／离桌账目、CSV、旧房间迁移、最终账单固定、聊天和倒计时的暂停恢复、重连、并发超时处理。JavaScript 语法检查需要 Node.js。

## 行动倒计时

新房间默认每次行动 30 秒，创建时可选 15／30／60／120／300 秒或不限时；房主可在两手之间修改。已有房间保留原来的时限设置。

牌桌上方、当前行动者座位和自己的操作区显示剩余时间及进度条；最后 10 秒变为黄色，最后 5 秒变为红色。聊天窗口同步显示轮到自己时的剩余秒数。刷新、重连、聊天或改名不会重置时限，下一位玩家获得完整行动时间。

房主暂停时保存剩余秒数，恢复后继续倒数。超时后由服务器执行操作：能过牌时自动过牌，需要跟注时自动弃牌，不自动跟注、加注或全下。超时记录会标在牌桌动态里。客户端到零时先停止接受下注并同步服务器结果；断线时以重连后的服务器状态为准。

## 房间聊天

点击房间顶部或下注操作区的「聊天」，即可与同一房间的成员发送文字。支持中文、emoji 和换行；电脑 Enter 发送，Shift + Enter 换行，中文输入法选字期间不会误发。聊天输入不会触发下注快捷键；轮到自己时，聊天窗会显示返回牌桌行动的提示。

新消息有未读角标；阅读旧消息时不会强制跳到最下面，可点击「回到最新」。草稿不会被牌局刷新清空，发送失败保留内容，重试同一条消息会去重。昵称和时间由服务器记录，改名不会改写此前消息的署名。

同一浏览器可同时保留多个房间的座位；一个页面保存聊天已读位置时，会保留其他房间新加入的座位。

每条最多 300 字，每位玩家每秒最多发送一条，房间仅保留最近 200 条，随 SQLite 数据库保存；刷新、重连和重启后可读取保留范围内的消息。消息仅房间成员可读写，退出后原座位凭据失效。赛后仍可聊天，聊天不会修改固定账单，也不包含在 CSV 账单中。文字按纯文本显示，不提供图片、语音、私聊或消息撤回。

聊天使用独立序号和增量查询，通常随约 1.1 秒牌桌轮询发现新消息；发言不会改变牌局操作版本或重置行动计时。

## 整场统计与赛后总结

房间右上角的「整场统计」可随时查看；只计入已结算手牌，不把正在下注的筹码误算为亏损。盈亏＝桌上筹码＋离桌带出－累计买入，补码不会增加盈利。全桌保留离桌记录，同名重新加入也会显示不同入座编号，个人累计不自动接续。

参与手数按实际获发底牌计算；分到任一主池或边池即算获胜一手，平分也计入，每手最多一次，因此获胜不等于本手净盈利。最大底池按已匹配的投入计算，排除无人跟注退回的筹码。曲线按逐手累计净盈亏绘制，可隐藏玩家、滑动查看各手进度；补码不会造成曲线跳涨。

时长从第一手开始，包含暂停及手间等待。房主在两手之间点击「结束本场」并确认后，生成固定的最终盈亏榜；该房间不再允许开牌、补码、改名或加入。下一场请新建房间。仍在座位上的玩家可回房间查看和导出；离桌会清除本浏览器的座位凭据，请先导出需要的账单。

支持 UTF-8 CSV 总账和逐手账单（时间列为 UTC），不含底牌、牌堆或座位凭据。进行中导出的是当前已结算快照。最近 50 手的侧栏仅用于快速回看；整场统计和逐手导出保留本场全部新增结算，服务重启后也可恢复。

升级前的旧房间缺少玩家标识和完整历史，无法可靠补算此前的手数、获胜、底池和曲线；界面会标明统计起点，沿用现有玩家的买入和筹码余额，时长从统计启用时起算。升级前已离桌的记录无法找回。需要完整统计时请新建房间。

## 部署

仓库包含 Docker 与 Docker Compose 配置。具体启动、HTTPS、持久化备份及 Cloudflare 的适配取舍见 [DEPLOYMENT.md](DEPLOYMENT.md)。

GitHub 仓库只保存源码；上传代码不会自动提供公网游戏地址。当前服务需部署到持续在线的主机。

### 临时手机联机测试

仓库的 **Actions → After Hours · Mobile preview → Run workflow** 可启动 5–60 分钟的手动联机测试。流程先运行测试，再在一次性 GitHub runner 上用全新数据库启动服务，通过 Cloudflare Quick Tunnel 提供 HTTPS 地址。就绪后的地址显示在仓库 Deployments 的 `mobile-integration-test` 环境以及运行摘要中。

此功能只用于开发阶段的手机与浏览器集成测试，不是常驻托管。结束或取消运行后，测试牌局清空；同一代码版本重新运行会替换该版本上一次测试，不同版本可独立测试至各自到期。它不会读取或上传本机房间和底牌数据。Cloudflare 临时域名在各地网络的可达性仍需实际验证。

## 当前限制

- 原型面向朋友间虚拟筹码娱乐，尚未经过商业平台级审计或长时间公网验证。
- 同步使用约 1.1 秒 HTTP 轮询。
- 座位凭据保存在浏览器本地。清除网站数据、换浏览器或换手机后，目前无法自动找回原座位。
- 未提供账号系统、邀请撤销、过期房间自动清理或多主机部署。
- 房间数据库含完整牌局及底牌，仅应由服务器管理员访问。数据库、邀请密钥、模型、个人笔记和运行日志不属于本仓库。
